# Week 3: SQL Advanced Analytics using Subqueries, CTEs, and Window Functions

## Objective

The objective of this assignment was to apply advanced SQL concepts such as Subqueries, Common Table Expressions (CTEs), and Window Functions to analyze sales data and generate business insights from the Superstore dataset.

---

## Tasks Performed

* Loaded the Superstore dataset for analysis.
* Created Customers, Orders, and Products tables.
* Inserted data into the tables using `SELECT DISTINCT`.
* Applied Subqueries to identify above-average sales and highest sales orders.
* Used CTEs for customer-level sales calculations and intermediate aggregations.
* Implemented Window Functions (`RANK()` and `ROW_NUMBER()`) for customer ranking and order analysis.
* Combined JOINs, CTEs, and Window Functions to generate customer sales rankings and business insights.
* Performed customer sales analysis, including:

  * Top customers
  * Bottom customers
  * Single-order customers
  * Above-average customers
  * Highest order value per customer
* Completed the Customer Sales Insights mini-project.
