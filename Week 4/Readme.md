# Week 4: Azure Cloud Fundamentals and Data Pipeline Implementation using Azure Data Factory

## Objective

The objective of this assignment was to understand Azure cloud services and build an end-to-end data pipeline using Azure Storage Account and Azure Data Factory (ADF).

---

## Tasks Performed

- Created an Azure Resource Group.
- Created an Azure Storage Account and Blob Container.
- Uploaded the source CSV dataset to Blob Storage.
- Created Azure Data Factory and explored its interface.
- Configured Linked Services and Datasets.
- Used the Get Metadata activity to retrieve file information.
- Built a Copy Data pipeline for data transfer.
- Executed and monitored the pipeline using Debug and Trigger.
- Configured IAM roles for secure access between Azure services.
- Implemented the mini-project by building an end-to-end Blob Storage → Azure Data Factory → Destination pipeline with metadata validation.

---

- Azure IAM
