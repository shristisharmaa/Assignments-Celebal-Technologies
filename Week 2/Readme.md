# Week 2: SQL-Based Data Analysis using Filtering, Aggregation, and Business Queries

## Objective

The objective of this assignment was to analyze sales data using SQL by applying filtering, aggregation, and business queries on the Superstore dataset.

---

## Tasks Performed

### Section A: Data Exploration

* Loaded the Superstore dataset into a SQL database.
* Explored the dataset using schema and sample data.

### Section B: Data Filtering

* Applied filters based on region, category, sales, and order date.

### Section C: Aggregation

* Performed aggregations using GROUP BY and aggregate functions.
* Calculated sales, profit, quantity, and average discount metrics.

### Section D: Business Queries

* Identified top products and customers.
* Analyzed monthly sales trends.
* Performed city-wise sales analysis.
* Analyzed discount and profit relationships.
* Identified orders with negative profit.

### Section E: Data Validation

* Checked for missing values.
* Identified duplicate orders.
* Validated invalid sales records.
